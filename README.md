# 🐍 42 Python Modules

A collection of Python exercises and projects completed as part of my journey through the 42 curriculum.

This repository documents my progression in Python, from fundamental programming concepts to more advanced topics, with a strong focus on problem-solving, clean code, and understanding how Python works.

## 📚 Modules

The repository is organized into modules, each focusing on different Python concepts.

| Module | Topics |
|---|---|
| Module 00 | Python fundamentals and basic syntax |
| Module 01 | Data structures, functions, and control flow |
| Module 02 | Object-oriented programming |
| Module 03 | Classes, inheritance, and advanced OOP |
| Module 04 | Iterators, generators, and functional programming |
| Module 05 | Exceptions, error handling, and testing |
| Module 06 | Modules, packages, and imports |
| Module 07 | Advanced Python concepts |
| Module 08 | Working with external libraries and APIs |
| Module 09 | Advanced exercises and practical applications |

*Topics may vary depending on the actual exercises and module requirements.*

## 🛠️ Technologies

- **Language:** Python 3
- **Version Control:** Git
- **Environment:** Linux

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ridahafidi/Python-Modules.git
cd Python-Modules
```

Navigate to the module you want to explore:

```bash
cd Module00
```

Run a Python exercise:

```bash
python3 exercise.py
```
